# 国内机器人 / 具身智能公司地图（检索起点）

**这是检索起点，不是在招证据，更不是全集。** 公司名单和团队变动很快（融资、合并、裁撤、方向调整都可能发生），
每一家都必须去官方招聘渠道确认当期 HC，再写进 `jobs.json`。不确定的公司先放进候选、标 `未知`。

⚠️ **这份清单一定会漏掉新公司。** 具身赛道每个月都有新公司成立并立刻开始高薪招人，成立 6–12 个月内的
公司几乎不会出现在任何静态名单里。**每一轮调研都必须先跑下面的「公司发现流程」**，再回到这份清单。
（真实教训：苏度科技 2025 年 5 月成立，一年内估值过百亿、官方在招 39 个岗位，但因为不在静态清单里被整轮漏掉。）

## 公司发现流程（每轮必跑，排在查 HC 之前）

按下面 6 类信源各扫一遍，把新公司并进目标清单，再逐家查在招：

**1. 学术会议（最能提前发现技术型团队）**
- ICRA / IROS / CoRL / RSS / RA-L：看**赞助商与展商名单**（Sponsors、Exhibitors、Career Fair 参展方）、
  workshop 赞助方、Demo Session 参展方。赞助机器人顶会的公司几乎都在招算法岗。
- 论文 affiliation：arXiv `cs.RO` 近半年的论文，作者单位里带公司名的直接记下来；获奖论文与
  benchmark 论文的合作单位尤其值得看。
- CVPR / NeurIPS / ICLR 的 robotics、embodied AI workshop 赞助方同理。

**2. 产业展会**
- 世界机器人大会 WRC（官网展商名录最全，能查到工商主体和所在城市）、中国国际工业博览会 CIIF、
  高交会、进博会、CES。展商名录通常带公司全称，可以直接拿去查工商和招聘。

**3. 融资与产业新闻（发现新公司最快的一条）**
- **按月检索**「具身智能 融资 2026年X月 汇总」这类盘点文（36氪/投中网/IT桔子/钛媒体/机器人大讲堂/
  雷峰网/量子位/机器之心），近 12 个月的每一期都过一遍。
- 「前 XX 负责人离职创业」类新闻通常比招聘公告早 3–6 个月出现，是最早的信号。

**4. 投资机构 portfolio**
- 财务投资方：高瓴、红杉、IDG、经纬、蓝驰、源码、真格、峰瑞、启明；
- 产业投资方：阿里、腾讯、美团、京东、宁德时代、比亚迪、小米、智元（也在对外投资）。
  翻它们的被投列表，比翻招聘网站更早发现公司。

**5. 开源与社区**
- GitHub / Hugging Face 组织页：LeRobot、OpenVLA、Isaac Lab 生态里活跃 contributor 的所属单位；
- 具身智能招聘汇总仓库、知乎招聘帖、公众号矩阵（注意看更新日期，社区汇总普遍滞后 3–12 个月）。

**6. 工商与名录**
- 企查查/天眼查按「具身智能 / 人形机器人 / 机器人」+ 注册地 + **近 12 个月新注册**筛选；
- 地方产业名录、专精特新名单、独角兽榜单（胡润、36氪）。

**发现之后**：每家新公司至少要落实三件事再进清单——① 工商主体与办公城市；② 技术方向是否命中用户的
方向标签；③ 官方招聘入口（官网、飞书/Moka 招聘系统、公众号）。三件都查不到的，仍然写一条
`hc状态: 未知` 的记录，注明「已发现但无法核实」，不要静默丢弃。

## 城市集群速览

- **北京**：具身创业公司最密集（银河通用、星海图、星动纪元、灵初、加速进化）+ 智源/人形中心。
- **上海**：智元、傅利叶、非夕、穹彻、节卡 + 国地中心、上海 AI Lab。
- **深圳**：逐际、众擎、优必选、腾讯 Robotics X、大族、越疆、跨维 + 硬件供应链。
- **杭州**：宇树、云深处、千寻智能 + 之江实验室。
- **苏州 / 南京 / 常州**：埃斯顿、艾利特、汇川生态、工业自动化岗位多。
- **合肥 / 成都 / 武汉**：本体与零部件、地方国资平台项目多，异地要问清驻场。

## 逐家要确认的 6 件事

1. 当期是否真的有 HC（官方渠道 + 发布/更新时间）；
2. 岗位是研究、算法落地、还是仿真/数据工程；
3. 薪资口径（月薪×几个月、有没有期权、期权怎么算）；
4. 是否接受应届 / 是否要求实习转正；
5. 工作地点与驻场要求（本体公司常有产线或客户现场）；
6. 稳定性信号：最近一轮融资时间、产品是否有真机交付、是否传出过裁员或业务调整。
